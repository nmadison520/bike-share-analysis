# Bike Share Usage Analysis Norfolk VA

## Overview 
This project receives and analyzes bike share data regarding usage in Norfolk over an extended period of time to identify patterns in usage and frequency, trip behavior, and trends.

## Tools used
-Python (pandas, numpy)
-VS Code
-Jupyter Notebook

## Key Questions 
-How does the number of rentals change from month to month throughout the year?
-How does the number of rentals vary across different temperature ranges?
-How frequently do rentals occur when the distance traveled is less than 2 miles?
-What is the month with the highestprecipitation?
-What is the average precipitation within this month?


## Key Findings
-The highest number of rentals occurs during September and increases as the months progress during a calendar year
-There is a positive correlation between number of rentals and temperature
-Rental frequency progressively increases from 0.0 to 0.50 mile rental distances, and then decreases from 0.5 miles up to but not including 2.0 miles
-The month with the highest precipitation is February, and the average value is about 0.185


## Dataset
Bike Share Norfolk- 2025
